# Kenya Meteorological Dashboard (Streamlit)

Files
- app.py – the dashboard
- data_utils.py – loading + cleaning
- Kenya_Meteorological_Synthetic_Dataset.csv – data (keep in the same folder as app.py)
- requirements.txt – libraries for deployment

Run locally:  pip install -r requirements.txt  then  streamlit run app.py

Deploy (Streamlit Community Cloud, free)
1. Create a public GitHub repo and upload the 4 files above.
2. Go to https://share.streamlit.io, sign in with GitHub, click "Create app".
3. Pick the repo, branch main, main file path app.py, then Deploy.
4. Copy the *.streamlit.app link into your report.
